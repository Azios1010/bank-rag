# Product documentation

This documentation defines the first product slice for `bank-rag`:
**SME unsecured working-capital loan pre-screening**.

The system is a decision-support tool. It produces an evidence-backed
pre-screening package for a credit officer; it does not make a final credit
decision or disburse funds.
